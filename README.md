# Little Secret Bot 🤖

A Telegram bot for anonymous messaging, built using `aiogram 3.9.0`.

## Features
- AI asistent
- Store messages in a database (PostegreSQL)
- Diary (saving some notes to Diary)

## Installation (Shell)

1. Clone the repository:
   ```
   git clone https://github.com/cayatceek/Conversation-bot.git
   cd Conversation-bot
   ```
   
2. Create a virtual environment (optional but recommended):
  ```
  python3 -m venv env
  ```

3. Install dependencies:
  ```
  pip install -r requirements.txt
  ```

4. Set up environment variables:
Create a .env file (or edit config.py if used instead):
BOT_TOKEN=your_telegram_bot_token

5. Running the Bot
  ```
  python3 main.py
  ```
